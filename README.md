# Kickoff

Kickoff is a YouTube-first desktop media dashboard for tracking videos, games, communities, and daily context.

The beta is planned as an Electron app with a React dashboard core that can later be reused in a browser extension host.

## First Beta Goals

- Local profile and dashboard shell
- YouTube-first media workspace with demo data
- Steam, Reddit, Weather, and Spotify now-playing widgets
- Custom themes and local image backgrounds
- Electron-ready desktop host

See [MVP_BUILD_PLAN.md](./MVP_BUILD_PLAN.md) for the full phased plan.
